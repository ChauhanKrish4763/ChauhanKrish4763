## 🛸 PolarisGCS — Cloud-Based Ground Control System

> *A full-featured, cloud-connected Ground Control Station for autonomous drone operations.*

PolarisGCS is one of my most ambitious projects — a cloud-native GCS (Ground Control System) built to manage, monitor, and control drone fleets in real time. It bridges the physical drone world with scalable cloud infrastructure.

**Key highlights:**
- 📡 **Real-time telemetry** streaming over WebSockets from drones to a cloud dashboard
- 🗺️ **Mission planning** — define, upload, and monitor autonomous flight paths
- ☁️ **Cloud-deployed** on AWS with a robust backend handling concurrent drone sessions
- 🔁 **MAVLink protocol integration** for ArduPilot-based drones
- 🖥️ Built with **FastAPI + React**, containerized with **Docker**
